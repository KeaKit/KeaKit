## 1. Horas de trabajo

Según el Commitment Agreement, cada miembro se compromete a dedicar 10 horas semanales a actividades y tareas relacionadas con la asignatura, incluyendo asistencia a clase. En un sprint de dos semanas, esto se traduciría en una aportación de 20 horas por miembro del equipo.

## 2. Aportaciones tangibles

Según el Commitment Agreement, cada miembro se compromete a contribuir semanalmente con al menos una aportación tangible al proyecto. En un sprint de dos semanas, esto se traduciría en una aportación de 2 commits por miembro del equipo.

## 3. Tareas completadas

Según el Commitment Agreement, cada miembro se compromete a completar al menos una tarea asignada cada semana. En un sprint de dos semanas, esto se traduciría en 2 tareas completadas por miembro del equipo.

## 4. Comprobación del cumplimiento del Commitment Agreement

Para comprobar el cumplimiento del Commitment Agreement, para cada miembro, se proponen los siguientes valores individuales:

- H = Horas trabajadas en el sprint; h = 1 si H >= 20.
- C = Nº commits reaalizados; c = 1 si C >= 2.
- T = Nº de tareas pasadas a Done; t = 1 si T >= 2.

ICCA = Índice de Cumplimiento del Commitment Agreement. ICCA = (h + c + t) / 3

Este índice puede tomar varios valores:
- 1 si el Commitment Agreement se está cumpliendo en su totalidad.
- 2 / 3 si se está cumpliendo moderadamente.
- 1 / 3 si apenas se está cumpliendo.
- 0 si no se está cumpliendo en absoluto.
